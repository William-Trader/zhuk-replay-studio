# 交易训练室

历史行情逐K回放、图表标注与**全真模拟交易**（双向 + 杠杆 + 保证金/强平 + 手续费/滑点/资金费），复盘模式随时开始、K线波动与成交量逐帧播放。**默认自动接入 Binance 实况行情**，内置 30 项技术指标与 Python 自定义指标引擎；离线时自动回退到内置 OKX BTCUSDT.P 快照。

## 实况行情（Binance）

- 打开应用自动拉取主流品种与最新 K 线（现货，1分/5分/15分/1小时/4小时/1天）。
- 「搜索品种」面板：全量 USDT 交易对（主流优先排序）+ 实时价格与涨跌幅，点击即切换；也可随时切回内置快照。
- 图表区底部工具栏：数据源状态、**载入更早**（向历史分页）、**刷新最新**（拉取新收盘K线）。
- **自选列表可增删**：默认 8 个主流币，报价约 12 秒刷新，点击切换品种；面板底部输入框加代码、每行右侧 ✕ 移除，右上「＋当前」把正在看的品种收进自选，增删结果存进本机设置（最多 24 个，删空也不会被默认列表塞回来）。
- **智能路由（macOS 应用内）**：主站不可达时自动回退 `data-api.binance.vision` 镜像，再尝试本机代理（默认探测 7890/1087/7891）；可在 `~/Library/Application Support/ZhukReplay/config.json` 配置 `proxyUrl`。
- 回放完全适配实况数据：选起点/按日期、逐根步进、倍速播放、回退同步撤回成交与挂单。

## 复盘模式（随时开始 · K线波动与成交量逐帧播放）

工具栏「复盘」一点即开，不需要预先安排时间：

- **逐帧波动播放**：当前K线在 1/速度 秒内走完 `开盘→极值→极值→收盘` 的真实路径，影线逐步伸出、实体随价格变化；成交量同步累积到末值。回放条上的「波动」按钮可切回整根跳变。
- **成交量面板自动就位**：开始复盘时自动加上「成交量」副图（若尚未启用），删除结果时又自动移除。
- **速度**：0.5×～32×（即每秒 0.5～32 根），按帧推进；步长可选整根 / 半根 / 1/4 根。
- **实时统计**：左上角复盘 HUD 显示已用时间、本次回放根数、成交笔数与已实现盈亏；进度条同步显示当前K线生长进度。
- **结束时二选一**：
  - **保留结果**：成交记录、盈亏与「复盘小结」一并存入本机项目（小结写入训练笔记），并把这一场战绩**存入训练档案**；
  - **删除结果**：回滚到复盘开始前的成交与笔记，回放位置复位，绘图保留。
- 复盘跑到数据末尾会自动弹出结果选择；复盘期间行情后台刷新不会抢走回放位置。

## 性能（对标 TradingView 的增量渲染思路）

回放每一步都只追加一根K线，因此全链路都走「增量」而不是全量重算：

- **聚合前缀索引**：高低周期聚合结果一次构建，回放游标只做切片＋重建正在形成的那一根（内置 6944 根分钟历史，15 分钟视图全回放实测 5.7ms → 0.1ms）。
- **增量 EMA20**：缓存每根K线的均线值，只在尾部续算（实测 6.3ms → 1.2ms）。
- **图表序列增量追加**：价格、EMA、副图指标都用 `update()` 追尾，不再每步 `setData()` 整表重建；回退、切周期、换品种、切图表类型时自动回退整表重建。
- **按帧推进的波动播放**：每根K线在一个帧循环内逐帧生长（开盘→极值→极值→收盘），成交量同步累积；增量渲染让逐帧更新仍保持每帧极少次序列调用。
- **性能面板**：右侧栏「标尺」按钮打开，实时显示渲染频率、渲染间隔、图表同步耗时、指标计算耗时与可见K线数。

实测（macOS 应用内，8× 回放，性能面板读数）：图表同步 ≈ 1.1ms/帧；增量追加模式下可见K线数与图表已同步点位数逐步一致（连续 1000+ 步无漂移，回退时正确整表重建）。

## 账户单位：U本位 · 币本位 · 币/张

- **U本位（线性）**：权益/盈亏按 USDT，名义 = 数量×价格。
- **币本位（反向合约）**：权益/保证金/盈亏按币计，名义 = 张数×面值（默认 100 USD/张），盈亏 = 面值×张数×(1/开仓 − 1/平仓)；强平价按反向公式解。
- **数量单位跟随当前品种**：按币时显示的是**当前品种**的基础币（BTCUSDT→BTC、BNBUSDT→BNB），换品种即时同步；
- **数量单位**：按币（基础币）或按张（合约）随时切换；下单面板实时给出**名义 USD / 占用保证金 / 折算币数量 / 手续费**预估。
- **切换本位自动折算权益**：U本位 10,000 USDT ⇄ 币本位 0.1275 BTC（按标记价），来回切换不丢钱。

## 交易真实度增强

- **实时资金费率**：读永续 `premiumIndex` 的真实费率与下次结算时间，直接显示在账户栏（实测 `0.0038% / 8h · 下次 16:00`），并把它并入边界表——历史之外的那次结算也按真实费率走。

- **成交量冲击滑点**：市价/止损成交按「基础滑点 + √(订单名义 / 该K线成交额) × 冲击系数」定价（默认基础 1bp、吃满整根冲击 8bp，上限 4×）。实测：0.05 BTC 在 15 分钟K线上成交 76,594.80，而同根收盘 76,584.52（+1.34bp）。
- **真实资金费率**：从 Binance 永续拉历史资金费率（`/fapi/v1/fundingRate`），按 **8 小时边界查表**结算；拉不到时自动回退到配置常数。7 天缓存 10 分钟。
- 复盘结果与 CSV 按**当前结算币**输出（U本位 2 位小数 / 币本位 8 位），表头写明单位。

## 数值口径（无浮点尾巴）

- **内部精度统一 8 位**：开平仓/加仓减仓/反手/强平/资金费每次变更后都把数量、均价、保证金、余额、已实现盈亏收到 8 位，`0.3-0.1` 不会再变成 `0.19999999999999998`。
- **显示按本位给位数**：U 本位 2 位、币本位 8 位；价格按最小变动对齐（tick 0.1 → 1 位）；比例固定 2 位百分比（保证金率 1 位）。
- **数量抹零**：`0.009999999999999998 → 0.01`、`1/3 → 0.33333333`。
- 覆盖范围：账户栏、持仓/订单/成交行、下单票据预估值、图例数值、复盘结果、复盘小结、CSV、提示语。

## 全真模拟账户（USDT 本位永续口径）

- **双向持仓**：开多 / 开空 / 加仓 / 部分平仓 / **反手**（一笔把多头翻成空头）；没有持仓时卖出即开空。
- **杠杆与保证金**：1–125× 可选，全仓 / 逐仓切换；实时显示**占用保证金、可用保证金、保证金率、强平价**，保证金率打满或价格触及强平价即**强制平仓**（逐仓最多亏该仓保证金，全仓吃账户权益）。
- **交易成本**：吃单 / 挂单手续费分开（默认 5bp / 2bp）、市价单滑点（默认 1bp）、永续**资金费率**每 8 小时（UTC 0/8/16）对持仓多空互付（默认 0.01%）。
- **委托**：市价 / 限价 / 止损，支持**只减仓**与**跟踪委托**；委托沿 bar 内真实价格路径触价（跳空按开盘价成交），不再按整根K线粗暴判定。
- **仓位保护**：开仓即带或事后设置**止损 / 止盈 / 跟踪止损**（成交后写入成交记录，平仓自动失效），按 bar 内路径先后顺序判定先触发哪一个。
- **精度**：价格按最小变动对齐、数量有最小下单量校验，下单前预校验保证金是否足够。
- **账户方案**：设置里可存多套方案（权益 / 杠杆 / 保证金模式 / 费率），一键切换口径；设置里还有「恢复默认」。
- **下单不打断回放**：复盘播放中随时开平仓，K线继续走。

## 复盘结果统计

结束复盘时给出完整战绩：成交笔数、**胜率**、盈亏比、平均盈利/亏损、最佳/最差、**多空分列**、**最大回撤**、平均持仓时长、手续费与资金费，并画出**权益曲线**；爆仓会在报告里标注。可**导出 CSV**（统计 + 逐笔成交，UTC+8 时间），配合「保留结果 / 删除结果」决定是否入库。

- **成交记录**按笔列出并标出**买卖 + 开平**（`买开 / 买平 / 卖开 / 卖平`）——双向持仓下「买」不等于「开」、「卖」也不等于「平」，标签由方向与动作共同决定。
- **已平仓**不是「所有卖单」，而是按**开 → 平**配对：方向、数量、开仓与平仓时间、持仓时长、本笔盈亏（按结算币位数）与成交原因（手动市价／限价单／止损／止盈／跟踪止损／强平），减仓的部分了结也会单列一行。

## 训练档案（跨场战绩 · 逐场可查）

工具栏「档案」一点即开（右侧栏也有入口，按钮上带已存场次）。单场复盘只看得到这一局，档案回答的是「练了这么多场，到底有没有进步」：

- **入库时机**：复盘结束点「保留结果」就落一条结构化战绩（时间、品种、周期、成交、胜率、盈亏、回撤、用时、爆仓、预警次数）；点「删除结果」的那一局不入档。档案与训练笔记、成交记录互不影响。
- **跨场汇总**：场次、累计盈亏、整体胜率、累计盈亏比、场均盈亏、场均成交、**跨场累计曲线与最大回撤**、最长连赢/连亏、最好/最差一场、累计手续费与资金费、累计复盘时长、爆仓次数。
- **分品种表现**：按品种聚合场次、成交、胜率与累计盈亏并排序 —— 一眼看出哪个品种是自己的提款机、哪个是绞肉机。
- **逐场明细**：每场一行（时间 / 品种周期 / 成交 / 胜率 / 盈亏 / 回撤 / 用时），可单独删除某一场（比如误操作或试验性打法）。
- **累计曲线口径**：跨场曲线按**已实现盈亏**累加（首点为 0），最大回撤取自这条曲线，与单场权益曲线的口径一致，不会把浮盈算成战绩。
- **单位不混算**：U 本位（USDT）与币本位（币）分开分组统计，多单位时对话框顶部出现单位切换；金额位数也按本位走（2 位 / 8 位）。
- **导出与归档**：一键导出 CSV（逐场明细 + 汇总表头，按单位分块，UTC+8 时间）；档案上限 500 场，超出丢最旧的；随项目文件一起导出、导入、清除。

## 指标库（33 项 · 平台形态）

**均线不再是独立开关**：EMA 已并入指标库（`EMA · 指数均线组`），新存档默认就是交易所那种形态 —— **MA5/10/20/60 均线组 + 成交量副图**。

- **均线组**：`MA · 均线组` / `EMA · 指数均线组` 一次加多条（逗号分隔，如 `5,10,20,60`，最多 6 条），每条独立配色，空/非法/重复周期自动清洗，预热不足的周期整段留空。
- **模板一键铺开**：交易所默认（MA5/10/20/60 + 成交量）· 趋势跟踪（EMA7/25/99 + 超级趋势 + MACD）· 震荡波段（布林带 + RSI + KDJ）· 短线快打（EMA9/21 + VWAP + 随机RSI）；套用时会替换同名指标，避免重复叠加。
- **可操作图例**（交易所/TradingView 形态）：每个指标一行，显示**每条序列的当前值**（MACD 有 DIF/DEA/柱、KDJ 有 K/D/J、成交量有涨量/跌量/均量），行内按钮直接**● 显隐 · ⚙ 改参 · ✕ 移除**；副图还有 **⇕ 高度**（1× → 1.5× → 2×）可拉高。
- **改参不用翻菜单**：点图例的 ⚙ 直接进参数编辑（当前值已填好），确定即生效。
- **收藏**：指标行右侧 ★ 收藏，收藏项置顶成「收藏」分组（本机持久化）。
- **副图轴标值**：副图指标把当前值显示在右轴（与交易所一致），主图叠加不占价格轴、数值在图例里。
- 完整清单：主图 15 项（均线组/单周期均线/通道/趋势/一目/VWAP/枢轴点）+ 副图 18 项（成交量/RSI/MACD/KDJ/随机/CCI/威廉/DMI/ATR/OBV/MFI/ROC/动量/AO/TRIX/CMF/标准差）。

## 行情数据链路（本机被墙时的走法）

本机直连 Binance 合约 API（fapi）会被墙，表现为品种清单正常但 K线报 `HTTP 502`。修复路径是**把 W1 服务器上的出网代理经 SSH 隧道映射到本机**，再让应用走它——不动服务器、不开公网端口：

```bash
# 1) 服务器上的代理端口（该机器 7890 是它自己的出网代理）
ssh -N -L 17890:127.0.0.1:7890 wt

# 2) 做成开机常驻（仓库内已带 plist）
cp mac/launchd/com.william.zk-market-tunnel.plist ~/Library/LaunchAgents/
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.william.zk-market-tunnel.plist
launchctl list | grep zk-market-tunnel        # 应看到进程

# 3) 让应用壳走这条代理（应用运行时执行一次即可；shell 配置存在 Application Support）
curl -s -X POST -H 'Content-Type: application/json' \
  -d '{"proxyUrl":"http://127.0.0.1:17890"}' http://127.0.0.1:8809/api/config
curl -s http://127.0.0.1:8809/api/config      # 确认已写入
```

壳内路由顺序为「直连 → 现货镜像 → 配置的代理」，并会**记住成功的路径**，所以首次请求略慢、之后直接走通。自查：

```bash
curl -s --proxy http://127.0.0.1:17890 "https://fapi.binance.com/fapi/v1/ticker/price?symbol=AAPLUSDT"
```

移除：`launchctl bootout gui/$(id -u)/com.william.zk-market-tunnel`，并把代理配置清空（`POST /api/config` 传空串）。
